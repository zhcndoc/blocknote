# 关于 BlockNote

BlockNote 是一个开源的模块化富文本编辑器，专为开发构建现代 Web 应用程序的开发者设计。BlockNote 聚焦于良好的开发者体验和现代的基于区块的用户体验，提供知识库、笔记应用、文档编辑器以及内部工具背后的文本编辑功能。

我们的目标是让开发者轻松地为他们的应用添加下一代文本编辑体验，其用户体验可媲美 Notion、Google Docs 或 Coda 等行业领先者。

BlockNote 由一支工程师团队开发——由 Matthew Lipski、Nick Perez 和 Yousef El-Dardiry 领导——他们在富文本编辑和实时协作软件领域拥有深厚的专业知识。该项目依靠我们的合作伙伴、赞助商和开源社区的支持得以实现。

## 与我们合作

BlockNote 被创业公司、公共机构和成熟企业用于支持其文档编辑体验。

我们与团队紧密合作，将 BlockNote 集成到他们的产品中，并打造定制化解决方案。

需要实际帮助或定制集成？请联系 team@blocknotejs.org。

## 支持项目

我们衷心感谢支持 BlockNote 的个人和组织。如果您使用 BlockNote，最简单的贡献方式是订阅 BlockNote Pro。

订阅将使您能够访问专业示例、享受我们团队的优先支持，并且获得 XL 包的商业许可。详情请参阅[价格页面](/pricing)。

我们自豪地获得像著名的 [NLNet foundation](https://www.nlnet.nl) 这样的组织支持，它们致力于推动更加开放、注重隐私且安全的互联网。

BlockNote 构建在 [ProseMirror](https://prosemirror.net/) 和 [Yjs](https://yjs.dev/) 之上——这两个卓越的开源项目也值得您的支持。

## 贡献
