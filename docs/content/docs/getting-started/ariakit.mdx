# 开始使用 Ariakit

[Ariakit](https://ariakit.org/) 是一个开源的无样式（无头）、基础组件库，专注于无障碍性。要在 Ariakit 中使用 BlockNote，可以从 `@blocknote/ariakit` 导入 `BlockNoteView`

```console tab="npm"
npm install @blocknote/core @blocknote/react @blocknote/ariakit
```

```console tab="pnpm"
pnpm add @blocknote/core @blocknote/react @blocknote/ariakit
```

```console tab="bun"
bun add @blocknote/core @blocknote/react @blocknote/ariakit
```

你可以使用自定义的 CSS 完全自定义样式，或者通过导入 `@blocknote/ariakit/style.css` 提供的默认样式文件。
