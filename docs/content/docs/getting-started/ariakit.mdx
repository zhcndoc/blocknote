# 开始使用 Ariakit

[Ariakit](https://ariakit.org/) 是一个开源的无样式（无头）、基础组件库，专注于无障碍性。

```console tab="npm"
npm install @blocknote/core @blocknote/react @blocknote/ariakit
```

```console tab="pnpm"
pnpm add @blocknote/core @blocknote/react @blocknote/ariakit
```

```console tab="bun"
bun add @blocknote/core @blocknote/react @blocknote/ariakit
```

要将 BlockNote 与 Ariakit 一起使用，您可以从 `@blocknote/ariakit` 导入 `BlockNoteView`。您可以使用自己的 CSS 完全自定义组件样式，或者通过 `@blocknote/ariakit/style.css` 样式表导入提供的默认样式。
