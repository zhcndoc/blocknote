# shadcn 入门

[shadcn/ui](https://ui.shadcn.com/) 是一个基于 [Radix](https://radix-ui.com/) 和 [TailwindCSS](https://tailwindcss.com/) 的开源 React 组件集合。

```console tab="npm"
npm install @blocknote/core @blocknote/react @blocknote/shadcn
```

```console tab="pnpm"
pnpm add @blocknote/core @blocknote/react @blocknote/shadcn
```

```console tab="bun"
bun add @blocknote/core @blocknote/react @blocknote/shadcn
```

要在 shadcn 中使用 BlockNote，可以从 `@blocknote/shadcn` 中导入 `BlockNoteView`，并从 `@blocknote/shadcn/style.css` 导入样式表。此版本的 `BlockNoteView` 预期用于已经使用 shadcn/TailwindCSS 的应用中，因此它本身不导入任何这些样式。

为了确保 Tailwind 为 BlockNote 组件使用的所有工具类生成必要的 CSS，请确保在导入 Tailwind 的样式表中添加 `@source` 指令：

```css
@import tailwindcss;
...
/* 指向你安装的 `@blocknote/shadcn` 包的路径。 */
@source "../node_modules/@blocknote/shadcn";
```

## shadcn 自定义

BlockNote 附带默认的 shadcn 组件。但是，通常你已经在项目中复制并可能自定义了自己的 shadcn 组件。
要让 BlockNote 使用你项目中的 shadcn 组件而非默认组件，可以通过 `BlockNoteView` 的 `shadcnComponents` 属性传递它们：

```tsx
import * as Button from "@/components/ui/button"
import * as Select from "@/components/ui/select"

return (
  <BlockNoteView editor={editor} shadcnComponents={{
    Select,
    Button,
    ...
  }} />
);
```

你可以传递以下 shadcn 模块中的组件：

- Badge
- Button
- Card
- DropdownMenu
- Form
- Input
- Label
- Popover
- Select
- Tabs
- Toggle
- Tooltip

<Callout type="warning" emoji="⚠️">
  为确保兼容性，你的 shadcn 组件不应使用 Portals （请注释掉
  DropdownMenu、Popover 和 Select 组件中的相关代码）。
</Callout>
