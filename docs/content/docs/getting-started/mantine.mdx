# Mantine 入门

[Mantine](https://mantine.dev/) 是一个开源的 React 组件集合。

```console tab="npm"
npm install @blocknote/core @blocknote/react @blocknote/mantine
npm install @mantine/core @mantine/hooks @mantine/utils
```

```console tab="pnpm"
pnpm add @blocknote/core @blocknote/react @blocknote/mantine
npm install @mantine/core @mantine/hooks @mantine/utils
```

```console tab="bun"
bun add @blocknote/core @blocknote/react @blocknote/mantine
npm install @mantine/core @mantine/hooks @mantine/utils
```

要在 Mantine 中使用 BlockNote，你可以从 `@blocknote/mantine` 导入 `BlockNoteView`，并从 `@blocknote/mantine/style.css` 导入样式表。

<Callout type={"info"}>
  如果你的应用已经使用了 Mantine UI，应该使用
  `@blocknote/mantine/blocknoteStyles.css` 样式表。它只包含 BlockNote 在 Mantine 核心样式基础上添加的样式，而
  `@blocknote/mantine/style.css` 包含了两者的样式。
</Callout>
