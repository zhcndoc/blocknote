# 行内容

默认情况下，BlockNote 中的 `InlineContent`（如段落等文本块的内容）可以是 `StyledText` 或 `Link` 对象。

以下是所有默认行内容及其支持的属性概述：

## 样式化文本

`StyledText` 是一种 `InlineContent` 类型，用于显示带样式的文本片段：

```typescript twoslash
/**
 * 样式可以应用于文本。
 */
type Styles = {
  bold: boolean;
  italic: boolean;
  underline: boolean;
  strike: boolean;
  code: boolean;
  textColor: string;
  backgroundColor: string;
};

// ---cut---
type StyledText = {
  type: "text";
  /**
   * 文本内容。
   */
  text: string;
  /**
   * 文本的样式。
   */
  styles: Styles;
};
```

## 链接

`Link` 对象表示指向 URL 的链接：

```typescript twoslash
type Styles = {
  bold: boolean;
  italic: boolean;
  underline: boolean;
  strike: boolean;
  code: boolean;
  textColor: string;
  backgroundColor: string;
};

/**
 * 链接中的任何文本内容
 */
type StyledText = {
  type: "text";
  text: string;
  styles: Styles;
};

// ---cut---
type Link = {
  type: "link";
  /**
   * 链接的内容。
   */
  content: StyledText[];
  /**
   * 链接的 href。
   */
  href: string;
};
```

## 默认样式

BlockNote 中的默认文本格式设置选项用默认架构中的 `Styles` 表示：

```typescript twoslash
type Styles = {
  /**
   * 文本是否加粗。
   * @default false
   */
  bold: boolean;
  /**
   * 文本是否斜体。
   * @default false
   */
  italic: boolean;
  /**
   * 文本是否带下划线。
   * @default false
   */
  underline: boolean;
  /**
   * 文本是否带删除线。
   * @default false
   */
  strike: boolean;
  /**
   * 文本是否以行内代码形式渲染。
   * @default false
   */
  code: boolean;
  /**
   * 文本颜色。
   * @default "default"
   */
  textColor: string;
  /**
   * 文本背景颜色。
   * @default "default"
   */
  backgroundColor: string;
};
```
