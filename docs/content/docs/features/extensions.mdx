# 扩展

BlockNote 包含一个扩展系统，允许你扩展编辑器的行为。扩展可以包含以下任意功能：

- 键盘快捷键
- 输入规则
- [ProseMirror 插件](https://prosemirror.net/docs/ref/#state.Plugin_System)
- [TipTap 扩展](https://tiptap.dev/docs/editor/extensions/custom-extensions/create-new)

## 创建扩展

你可以使用 `createExtension` 函数来创建扩展：

```typescript
type Extension = {
  key: string;
  keyboardShortcuts?: Record<
    string,
    (ctx: { editor: BlockNoteEditor; }) => boolean
  >;
  inputRules?: {
    find: RegExp;
    replace: (props: {
      match: RegExpMatchArray;
      range: { from: number; to: number };
      editor: BlockNoteEditor;
    }) =>
      | PartialBlock
      | { text: string; styles: Record<string, string | boolean> }
      | PartialInlineContent
      | undefined;
  }[];
  prosemirrorPlugins?: Plugin[];
  tiptapExtensions?: AnyExtension[];
}

const CustomExtension = createExtension({
  key: "customBlockExtension",
  keyboardShortcuts: ...,
  inputRules: ...,
  prosemirrorPlugins: ...,
  tiptapExtensions: ...,
});
```

下面是可以传入 `createExtension` 的选项说明：

`key:` 扩展的名称。

`keyboardShortcuts?:` 键盘快捷键用于在编辑器中按下某键组合时执行代码。键名与 [`KeyboardEvent.key` 属性](https://developer.mozilla.org/en-US/docs/Web/API/UI_Events/Keyboard_event_key_values) 中使用的一致。接受一个对象，该对象将键名组合（例如 `Meta+Shift+ArrowDown`）映射到函数，函数在处理该按键事件时返回 `true` ，否则返回 `false`。函数只有一个参数：

- `ctx:` 包含 BlockNote 编辑器实例的对象。

`inputRules?:` 一组声明式输入规则，可用于区块、样式或内联内容。请参阅[输入规则](#input-rules)。

`prosemirrorPlugins?:` 一个 [ProseMirror 插件](https://prosemirror.net/docs/ref/#state.Plugin_System)数组。

`tiptapExtensions?:` 一个 [TipTap 扩展](https://tiptap.dev/docs/editor/extensions/custom-extensions/create-new) 数组。

## 输入规则

输入规则是包含 `find` 和 `replace` 的普通对象。例如，将以 `# ` 开头的段落转换为标题：

```typescript
import { createExtension } from "@blocknote/core";

const HeadingShortcut = createExtension({
  key: "heading-shortcut",
  inputRules: [
    {
      find: /^#\s$/,
      replace: () => ({ type: "heading", props: { level: 1 } }),
    },
  ],
});
```

`replace` 回调会收到 `{ editor, match, range }`。返回 [`PartialBlock`](/docs/reference/editor/manipulating-content#partial-blocks) 可转换当前区块；返回 `undefined` 则保持不变。撤销操作会恢复完整的字面输入文本，包括触发字符。

返回值的形状决定执行的操作：`{ text, styles }` 会应用样式；字符串或数组会替换内联内容；部分区块会更新当前区块：

```typescript
import { createExtension } from "@blocknote/core";

const TextShortcuts = createExtension({
  key: "text-shortcuts",
  inputRules: [
    {
      find: /\*\*([^*]+)\*\*$/,
      replace: ({ match }) => ({ text: match[1], styles: { bold: true } }),
    },
    {
      find: /->$/,
      replace: () => "→",
    },
  ],
});
```

样式规则会保留匹配结果中的 `text`，移除其两侧分隔符（保留开头空白），并应用 `styles`，而不丢弃已有格式。内联规则会将整个匹配项替换为字符串或 BlockNote 内联内容数组，包括自定义内联内容。两种规则都可以返回 `undefined` 表示不处理该匹配项。与样式关联的扩展可以和样式 spec 放在一起。

区块规则也会将普通 Enter 匹配为换行。样式规则和内联规则只会在输入文本时运行。请在创建编辑器时注册规则；不支持运行时添加输入规则。

自定义 TipTap 扩展仍可使用 `addInputRules`，但它们会沿用 TipTap 自身的输入规则和撤销行为，而不使用 BlockNote 共享的引擎。

## 向编辑器添加扩展

扩展可以单独通过 [编辑器选项](/docs/reference/editor/overview#options) 添加到编辑器中，或者作为 [自定义区块](/docs/features/custom-schemas/custom-blocks) 的一部分添加。

### 直接添加到编辑器

`extensions` [编辑器选项](/docs/reference/editor/overview#options) 接受一个扩展数组，用于添加到编辑器中：

```typescript
const editor = useCreateBlockNote({
  extensions: [
    // 在此添加扩展：
    createExtension({ ... })
  ],
});
```

### 添加到自定义区块

创建 [自定义区块](/docs/features/custom-schemas/custom-blocks#creating-a-custom-block-type) 时，使用 `createReactBlockSpec`，你可以将扩展数组作为第三个参数传入：

```typescript
const createCustomBlock = createReactBlockSpec(
  {
    // 区块配置
    ...
  },
  {
    // 区块实现
    ...
  }
  [
    // 在此添加扩展：
    createExtension({ ... })
  ],
);
```
