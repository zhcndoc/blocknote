# 格式互操作性

BlockNote 兼容几种不同的存储格式，每种格式都有其优缺点。本指南将向您展示如何使用它们。

## 概述

对于编辑器来说，格式可能比较棘手。编辑器需要能够读取和写入每种格式。

<Callout type="info">
  如果元素在此转换过程中未被保留，我们称转换为
  _有损_。虽然我们理想上支持每种格式，但 **其他格式可能不支持所有 BlockNote 内容。**
</Callout>

请参阅下表以查看我们支持的格式及其有损性的总结：

| 格式                                                                     | 导入       | 导出       | [仅限专业版](/pricing) |
| :---------------------------------------------------------------------- | :--------- | :--------- | :-------------------- |
| **BlockNote JSON (`editor.document`)**                                 | ✅         | ✅         | ❌                    |
| **BlockNote HTML (`blocksToFullHTML`)**                                | ✅         | ✅         | ❌                    |
| **标准 HTML (`blocksToHTMLLossy`)**                                    | ✅（有损） | ✅（有损） | ❌                    |
| **Markdown (`blocksToMarkdownLossy`)**                                 | ✅（有损） | ✅（有损） | ❌                    |
| **[PDF](/docs/features/export/pdf)** (`@blocknote/xl-pdf-exporter`)    | ❌         | ✅         | ✅                    |
| **[DOCX](/docs/features/export/docx)** (`@blocknote/xl-docx-exporter`) | ❌         | ✅         | ✅                    |
| **[ODT](/docs/features/export/odt)** (`@blocknote/xl-odt-exporter`)    | ❌         | ✅         | ✅                    |
| **[电子邮件](/docs/features/export/email)** (`@blocknote/xl-email-exporter`)| ❌       | ✅         | ✅                    |

<Callout>
  **提示：** 推荐使用 **BlockNote JSON (`editor.document`)** 来存储文档，因为它是最持久的格式且保证无损。
</Callout>

## 使用区块（JSON）

BlockNote 使用 JSON 结构（一个 `Block` 对象数组）作为其原生格式。这是推荐的存储文档方式，因为它是**无损**的，能够完整保留内容的精确结构和所有属性。

### 保存区块

获取最新内容的最佳方法是在使用原生 JS 时使用 `editor.onChange` 回调，或在 React 中使用 `useEditorChange` 钩子。每当编辑器内容发生变化时，该函数都会被调用。

```tsx twoslash
import React from "react";
import { useCreateBlockNote, useEditorChange } from "@blocknote/react";
import { BlockNoteView } from "@blocknote/mantine";

// ---cut-start---
function storeToDB(blocks: string) {
  console.log(blocks);
}
// ---cut-end---

export default function App() {
  const editor = useCreateBlockNote();

  useEditorChange((editor) => {
    // 当前文档内容的字符串形式
    const savedBlocks = JSON.stringify(editor.document);
    //                                 ^^^^^^^^^^^^^^^

    storeToDB(savedBlocks);
  }, editor);

  return <BlockNoteView editor={editor} />;
}
```

### 加载区块

加载内容时，可以在创建编辑器时使用 `initialContent` 属性。您可以传入之前保存的 `Block` 对象数组。

```tsx
import { useCreateBlockNote } from "@blocknote/react";
import type { Block } from "@blocknote/core";
import { BlockNoteView } from "@blocknote/mantine";

export default function App({
  initialContent,
}: {
  initialContent?: Block<any, any, any>[];
}) {
  const editor = useCreateBlockNote({
    initialContent,
  });

  return <BlockNoteView editor={editor} />;
}
```

## 使用 HTML

BlockNote 提供了将内容在 `Block` 对象和 HTML 之间转换的工具。请注意，转换为标准 HTML 可能是**有损**的。

### 保存为 HTML

要将文档转换为 HTML 字符串，可以使用 `editor.blocksToFullHTML(blocks: Block[])`：

```tsx twoslash
import React from "react";
import { useCreateBlockNote, useEditorChange } from "@blocknote/react";
import { BlockNoteView } from "@blocknote/mantine";

// ---cut-start---
function storeToDB(html: string) {
  console.log(html);
}
// ---cut-end---

export default function App() {
  const editor = useCreateBlockNote();

  useEditorChange(async (editor) => {
    const html = await editor.blocksToFullHTML(editor.document);
    //                 ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
    // 你现在可以保存这个 HTML 字符串
    storeToDB(html);
  }, editor);

  return <BlockNoteView editor={editor} />;
}
```

<Callout type="info">
  `editor.blocksToFullHTML` 方法会输出 BlockNote 内部格式的 HTML。如果想导出为标准 HTML，可以改用 `editor.blocksToHTMLLossy`。
</Callout>

### 从 HTML 加载

加载 HTML 内容时，首先需要使用 `editor.tryParseHTMLToBlocks()` 将 HTML 转换为 `Block` 对象数组，然后再插入编辑器。

```tsx twoslash
import React from "react";
import { useEffect } from "react";
import { useCreateBlockNote } from "@blocknote/react";
import { BlockNoteView } from "@blocknote/mantine";

const myHTML = "<p>这是一个段落。</p>";

export default function App() {
  const editor = useCreateBlockNote();

  useEffect(() => {
    // 初始化时替换区块内容
    // 你也可以在渲染编辑器之前调用此方法
    async function loadHTML() {
      const blocks = await editor.tryParseHTMLToBlocks(myHTML);
      //                   ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
      editor.replaceBlocks(editor.document, blocks);
    }
    loadHTML();
  }, [editor]);

  return <BlockNoteView editor={editor} />;
}
```

## 使用 Markdown

BlockNote 也支持 Markdown 的相互转换。但转换为 Markdown 及从 Markdown 转换都是**有损**的。

<Callout type="warning">
  BlockNote 提供了一个**最小化**的 Markdown 解析器/序列化器，目标是
  常见的 CommonMark + GFM 子集（标题、段落、列表、任务列表、
  表格、代码、引用块、链接、图片、强调、删除线、硬换行）。支持所有 Markdown 变体（CommonMark、GFM、MDX、Pandoc
  以及各种扩展）并不是编辑器的目标。如果您的使用场景
  需要超出此子集的 Markdown 功能，**请自行将 Markdown 解析为
  HTML**（使用诸如 [`marked`](https://github.com/markedjs/marked),
  [`markdown-it`](https://github.com/markdown-it/markdown-it), 或
  [`remark`](https://github.com/remarkjs/remark) 这样的库），并将生成的
  HTML 传递给 `editor.tryParseHTMLToBlocks`——HTML 是 BlockNote 用于
  任意粘贴的格式，且具有更广泛的互操作性。
</Callout>

### 保存为 Markdown

要将文档转换为 Markdown 字符串，可以使用 `editor.blocksToMarkdownLossy()`：

```tsx twoslash
import React from "react";
import { useCreateBlockNote, useEditorChange } from "@blocknote/react";
import { BlockNoteView } from "@blocknote/mantine";

// ---cut-start---
function storeToDB(markdown: string) {
  console.log(markdown);
}
// ---cut-end---

export default function App() {
  const editor = useCreateBlockNote();

  useEditorChange(async (editor) => {
    const markdown = await editor.blocksToMarkdownLossy(editor.document);
    //                     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
    // 你现在可以保存这个 Markdown 字符串
    storeToDB(markdown);
  }, editor);

  return <BlockNoteView editor={editor} />;
}
```

### 从 Markdown 加载

加载 Markdown 内容时，首先需要使用 `editor.tryParseMarkdownToBlocks()` 将 Markdown 转换为 `Block` 对象数组，然后插入编辑器。

```tsx twoslash
import React from "react";
import { useEffect } from "react";
import { useCreateBlockNote } from "@blocknote/react";
import { BlockNoteView } from "@blocknote/mantine";

const myMarkdown = "这是一个带有 **加粗** 文字的段落。";

export default function App() {
  const editor = useCreateBlockNote();

  useEffect(() => {
    async function loadMarkdown() {
      const blocks = await editor.tryParseMarkdownToBlocks(myMarkdown);
      //                   ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
      editor.replaceBlocks(editor.document, blocks);
    }
    loadMarkdown();
  }, [editor]);

  return <BlockNoteView editor={editor} />;
}
```

## 仅导出格式

BlockNote 还支持导出到以下额外格式：

- DOCX
  - 通过 [`@blocknote/xl-docx-exporter` 包](/docs/features/export/docx)
- PDF
  - 通过 [`@blocknote/xl-pdf-exporter` 包](/docs/features/export/pdf)
- ODT
  - 通过 [`@blocknote/xl-odt-exporter` 包](/docs/features/export/odt)
- 电子邮件
  - 通过 [`@blocknote/xl-email-exporter` 包](/docs/features/export/email)
