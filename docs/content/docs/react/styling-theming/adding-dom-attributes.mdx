# 添加 DOM 属性

BlockNote 允许你向编辑器中的各种 DOM 元素添加自定义的 HTML 属性。这使你能够对样式和功能进行精细控制。

## 可用的 DOM 元素

以下 DOM 元素可以接收自定义属性：

- **`editor`**：主编辑器容器，不包括菜单和工具栏
- **`block`**：单个区块的容器元素
- **`blockGroup`**：顶级和嵌套区块的包装容器
- **`blockContent`**：区块内容的包装容器
- **`inlineContent`**：区块内富文本内容的包装容器
